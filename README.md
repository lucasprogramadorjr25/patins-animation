## 💻 Sobre o Projeto

O **Patins Animation** é uma aplicação desenvolvida para praticar e demonstrar habilidades em animações CSS e manipulação de elementos no DOM. O objetivo principal foi criar uma interface dinâmica e atraente, onde o foco é a apresentação visual de um produto (patins) com transições suaves e interatividade.

Este projeto faz parte do meu portfólio como desenvolvedor, focado em aprimorar técnicas de **Front-end** e **UI Design**.

## 🚀 Como executar o projeto

Você pode acessar o link de demonstração acima ou rodar o projeto localmente na sua máquina:

### Pré-requisitos

Antes de começar, você vai precisar ter instalado em sua máquina o [Git](https://git-scm.com). Além disso, é bom ter um editor para trabalhar com o código, como o [VSCode](https://code.visualstudio.com/).

### Rodando a aplicação

```bash
# Clone este repositório
$ git clone [https://github.com/lucasprogramadorjr25/patins-animation.git](https://github.com/lucasprogramadorjr25/patins-animation.git)

# Acesse a pasta do projeto no terminal/cmd
$ cd patins-animation

# Abra o arquivo index.html no seu navegador
# OU se estiver usando o VSCode, use a extensão "Live Server" para abrir o projeto.
